# Stock Screener App

This app scans live/polled market data and displays paginated market rows with sorting controls. The browser refreshes the current page every 30 seconds by default. The UI can sort the loaded page by current price, pre-market price, post-market price, and each percent-change field.

Pages:

- My Top US Stocks: top 200 US stocks ranked high-to-low by the active US session change metric
- Top Indian Stocks: top 250 NSE stocks from the full Indian universe, ranked high-to-low by current change %
- Top Crypto: top 250 crypto assets from the full crypto universe, ranked high-to-low by 24h change %
- US Stocks: Yahoo Finance quote/chart data for symbols in `data/us-symbols.json`
- Indian Stocks: Yahoo Finance NSE symbols in `data/india-symbols.json`
- All Crypto: Hyperliquid spot assets in `data/crypto-symbols.json`

The US universe is generated from NASDAQ Trader symbol directory files and currently contains 12,317 listed US stocks and ETFs. The app paginates this universe and refreshes live prices for the active page every 30 seconds. This avoids making 11,000+ unofficial Yahoo requests every refresh cycle.

The Indian universe is generated from NSE's listed-equities file and currently contains 2,141 NSE stocks. The crypto universe is generated from Hyperliquid spot metadata.

Yahoo extended-hours prices are derived from minute candles requested with `includePrePost=true` when the direct quote API does not return pre/post fields. Crypto has no pre/post market sessions, so those fields remain blank for crypto rows.

The US top stock page checks a market proxy's Yahoo session state. During pre-market it ranks by pre-market change %, during regular hours it ranks by current change %, and after close/weekends/holidays it ranks by post-market change % when available. Indian top stocks always rank by current change %. Crypto ranks by 24h/current change %.

Top pages are cached server-side for fast refreshes. If a cached top page is available, the app returns it immediately and refreshes the data in the background instead of making the browser wait through a full scan.

Indian stocks do not have US-style continuous pre-market and post-market sessions. The app enriches Indian rows with NSE pre-open prices where NSE provides them. Post-market fields remain blank because NSE's post-close session trades at the official closing price rather than a separate continuous post-market price.

Optional Zerodha Kite support can be enabled for Indian live quotes by setting `KITE_API_KEY` and `KITE_ACCESS_TOKEN` in `.env`. Kite Connect requires a Zerodha developer app and a valid daily access token.

## Update Universes

```powershell
npm.cmd run update:us-universe
npm.cmd run update:india-universe
npm.cmd run update:crypto-universe
```

## Run

```powershell
Copy-Item .env.example .env
notepad .env
npm.cmd start
```

Open `http://localhost:3000`.

## Supabase table

The app writes scan results through the Supabase REST API into `SUPABASE_SIGNALS_TABLE`, which defaults to `stock_signals`.

Expected columns:

```sql
create table if not exists stock_signals (
  id bigint generated by default as identity primary key,
  market text not null,
  symbol text not null,
  name text,
  exchange text,
  price numeric,
  pre_market_price numeric,
  post_market_price numeric,
  change_amount numeric,
  change_percent numeric,
  pre_market_change_percent numeric,
  post_market_change_percent numeric,
  volume numeric,
  signal_rank integer,
  source text,
  scanned_at timestamptz not null,
  raw jsonb,
  unique (market, symbol, scanned_at)
);
```

Use the service-role key only on the server, never in browser code.

For an existing table, add the new fields with:

```sql
alter table stock_signals
  add column if not exists pre_market_price numeric,
  add column if not exists post_market_price numeric,
  add column if not exists pre_market_change_percent numeric,
  add column if not exists post_market_change_percent numeric;
```

## Expanding exchange coverage

Yahoo Finance does not provide an official free "all exchanges" symbol master. To broaden US or Indian coverage beyond the generated files, add more Yahoo-compatible symbols to:

- `data/us-symbols.json`
- `data/india-symbols.json`

The server refreshes live prices for the active page instead of refreshing every symbol in the universe at once.
